# Demo recording guide — 3 minutes + 30 seconds

Use only after the real domain, Google sign-in, save/retrieve and deployment checks work. Record the live product; do not read unperformed actions as completed evidence.

0:00–0:30 — Show the real venture domain. “This is SkillProof MX. It helps a recent graduate in Mexico demonstrate Excel skills through evidence that a human reviewer can inspect. This Week 12 core focuses on one financial-analysis task.”

0:30–1:00 — Sign in with an invented test account. Download the fictional workbook. “The criteria are explicit, the data is fictional and the candidate sees the required cells before beginning.”

1:00–1:45 — Upload completed workbook and explanation. Show the evidence report. “Each finding points to a cell and formula. Verified means the supported calculation and source references match the criterion. Contradictory means the calculation differs. Pending means the system cannot verify it yet.”

1:45–2:15 — Show an incorrect or unsupported formula. “Formula presence alone does not prove the reasoning. This system recalculates supported arithmetic and leaves unsupported formulas for review. The explanation is labeled simulated if no live AI service is available.”

2:15–2:45 — Show saved status, refresh and recover latest report. Download report. “The report is private to this signed-in account. The workbook itself is not stored.” Only say this after verifying live RLS.

2:45–3:00 — Show correction/reupload. “The result describes this file, not the person's identity, and it does not decide hiring. Human review is not automatically requested.”

3:00–3:30 — What changed my mind: “I initially thought displaying a formula and a score was enough to make the assessment transparent. Testing showed that even an unrelated formula could receive traceability credit. I changed the core to check supported calculations, show their evidence and leave uncertainties visible. I also learned that promising a human review is not the same as having an accountable person available. The next test is whether this actually reduces total review effort without reducing quality; a 10-to-1 improvement is still unproven.”
