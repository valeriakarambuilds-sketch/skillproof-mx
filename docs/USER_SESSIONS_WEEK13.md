## Provisional ranking from the five supplied summaries

1. Submission blockage (P02/P05): users cannot tell whether selecting a file completes delivery. Threat: incomplete assessments and support/rework undermine operating savings. Fix implemented: explicit .xlsx + explanation requirements, selected/not-sent status, named send button, in-progress status and server-response-based receipt.
2. Result interpretation (P01): users may attribute reasoning review to numerical checks. Threat: unsupported assessment confidence. Provisional status and separate reasoning remain required; validate comprehension with an actual retest.
3. Required evidence and next steps (P03/P04): unclear explanation requirement, correction and retry. Threat: avoidable rework and abandonment. Explicit two-item delivery instructions are included in this correction; individual correction guidance remains to be tested.

Severity takes priority over frequency; this ranking is provisional while exact quotes and session evidence remain missing. No observed grading error was reported in these summaries. If a harmful grading or misleading-result failure is confirmed, rerank it above navigation friction.

## Retest task — P02 or P05

Ask without coaching: “Choose your completed Excel, submit it, and tell me when you know the system received and evaluated it.” Record whether selection is correctly understood as not sent, whether the send button is found, whether actual receipt is identified, assistance and exact quote. Compare tested versions and preserve before/after evidence. Retest and return-use signal are pending; a developer test does not replace either.
